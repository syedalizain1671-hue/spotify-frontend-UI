# Spotify Web Player Clone

A responsive front-end clone of the Spotify Web Player interface built to showcase interactive UI layout design, audio management, and CSS styling.

## Tech Stack
• **HTML5** – Semantic markup and page structure
• **CSS3 / Utility Classes** – Styling, responsive layouts, flexbox, and CSS grid
• **JavaScript (ES6+)** – Audio controls, dynamic playlist rendering, and DOM manipulation

## Features
• Custom audio playback controls (Play, Pause, Track switching)
• Fully responsive layout styled to closely match Spotify's desktop interface
• Dynamic library listing and custom playlist navigation
